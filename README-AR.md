# موقع الأستاذ خالد صبح + Dashboard + Supabase

## الملفات
- `index.html`: الموقع الأصلي بعد ربط تحميل المذكرات والمراجعات بقاعدة البيانات عند إعداد Supabase. فيديوهات يوتيوب تظل عبر YouTube Data API.
- `admin.html`: لوحة تحكم خاصة بالمدرّس لتسجيل الدخول وإضافة/تعديل/حذف المحتوى ورفع PDF.
- `js/config.js`: إعدادات Supabase ومفتاح YouTube الاختياري.
- `js/supabase-client.js`: إنشاء اتصال Supabase.
- `js/admin.js`: منطق لوحة التحكم.
- `supabase-setup.sql`: الجداول والسياسات الأمنية وStorage bucket.

## خطوات الربط (مرة واحدة)
1. افتح https://supabase.com وأنشئ مشروعًا جديدًا.
2. من Project Settings → API انسخ **Project URL** و **anon/public key** (أو publishable key)، وضعهما في `js/config.js`.
   - ممنوع وضع `service_role` أو أي secret key في ملفات الواجهة الأمامية.
3. من SQL Editor في Supabase افتح `supabase-setup.sql` ونفّذه بالكامل.
4. من Authentication → Users أنشئ مستخدمًا للمدرّس باستخدام بريده وكلمة مرور قوية. لا تضف زر إنشاء حساب عام للموقع.
5. انسخ UUID الخاص بالمستخدم، ثم نفّذ الاستعلام التالي بعد استبدال `PASTE-USER-UUID-HERE`:

   ```sql
   insert into public.admin_users (user_id)
   values ('PASTE-USER-UUID-HERE');
   ```

6. ارفع مجلد المشروع كله إلى استضافة static مثل Vercel أو Netlify. حافظ على المسارات كما هي، ويكون `index.html` و`admin.html` في جذر المشروع.
7. افتح `/admin.html` وسجّل الدخول بحساب المدرّس. أضف مذكرة تجريبية مع PDF، وفعّل «منشور على الموقع»، ثم تأكد أنها تظهر في تبويب المذكرات/المراجعات في الصفحة الرئيسية.

## YouTube API
مفتاح YouTube الموجود في الملف الذي أرسلته كان ظاهرًا في JavaScript؛ لذلك أزلته من النسخة الجديدة. لو عايز الفيديوهات تتحدّث مباشرة، حط مفتاح YouTube Data API v3 في `youtubeApiKey` داخل `js/config.js` بعد تقييده من Google Cloud بحيث يسمح بـ YouTube Data API v3 وبـ HTTP referrers الخاصة بموقعك فقط. المفتاح الذي يظهر في المتصفح ليس سرًا، لذا لازم يكون مقيّدًا. لو تركته فارغًا، الموقع يستخدم بيانات الفيديو التجريبية الموجودة بالملف.

## ملاحظات مهمة
- لو Supabase غير مُعدّ، الموقع يظل يفتح بالمحتوى التجريبي الموجود في HTML، والداشبورد تعرض تنبيه الإعداد.
- السياسات تمنع الزوار من إضافة أو تعديل أو حذف المحتوى. الزوار يرون المحتوى المنشور فقط.
- PDF bucket عام للقراءة حتى يستطيع الطلاب فتح الملفات؛ الكتابة والحذف محصوران بالمدير.
- اختبر الإضافة والتعديل والحذف ورفع PDF على نسخة تجريبية قبل إرسال الموقع للمدرّس.
